Guia de Deploy Real

Como colocar isso online?

Para que as IAs editem seus vídeos de verdade, você precisa conectar este HTML a um servidor Backend. O HTML é só o painel de controle; o servidor é quem fará o "trabalho sujo".

1 A Arquitetura (Onde hospedar)

Você precisará de 3 peças fundamentais:

  • Frontend (Este Painel): Hospede de graça na Vercel ou Netlify. É fácil, basta subir o código HTML.
  • Backend (Servidor Python): Hospede no Render.com (usando Docker). Por que Docker? Porque para cortar vídeos, o servidor precisa do programa `FFmpeg` instalado no sistema operacional, e o Docker permite isso.
  • Armazenamento em Nuvem: Use Amazon S3. O seu servidor Python vai baixar a live lá da Twitch, salvar no S3, cortar, e devolver o link final para o Frontend.

2 Código do Servidor (Python/FastAPI)

No Render.com, você rodará este código para que o Gemini leia seu vídeo e o FFmpeg corte as partes boas:

from fastapi import FastAPI import google.generativeai as genai from moviepy.editor import VideoFileClip import json app = FastAPI() genai.configure(api_key="SUA_CHAVE_GEMINI_AQUI") @app.post("/cortar-video-viral") async def gerar_cortes(video_url: str): # 1. IA analisa o video inteiro e acha os minutos de ouro prompt = "Retorne um JSON com os tempos (início e fim) da melhor jogada." model = genai.GenerativeModel("gemini-1.5-pro") ia_resposta = model.generate_content([video_url, prompt]) dados = json.loads(ia_resposta.text) # 2. MoviePy (usando FFmpeg) corta fisicamente o vídeo video = VideoFileClip(video_url) corte = video.subclip(dados['inicio'], dados['fim']) # 3. Crop vertical 9:16 para TikTok (w, h) = corte.size corte_vertical = corte.crop(x1=w/2 - (h*9/16)/2, width=h*9/16) corte_vertical.write_videofile("pronto_pro_tiktok.mp4", codec="libx264") return {"status": "sucesso", "arquivo": "pronto_pro_tiktok.mp4"}
